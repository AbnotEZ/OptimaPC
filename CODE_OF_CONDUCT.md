# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (en [español](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)).

En resumen: trata a los demás con respeto, acepta las críticas constructivas, céntrate en lo mejor para la comunidad y no toleres el acoso, los insultos ni la publicación de datos privados de otras personas.

## Cómo informar

Comunica los incidentes a quien mantenga el repositorio mediante el informe privado de GitHub (pestaña *Security*) o un mensaje privado a su cuenta de GitHub. Los informes se tratarán de forma confidencial.

Este documento no incluye direcciones de correo: quien mantenga el repositorio publicado podrá añadir un canal de contacto propio.
